# Student Management System

## Description

Student Management System is a Java application designed to manage student information in an organized and simple way. The system allows users to add, view, update, search, and delete student records.

This project was developed using Java and SQL Server as a simple example of building a student management application.

## Features

- **Add Students:** Add new students to the system.
- **View Students:** Display student records and their information.
- **Update Students:** Modify existing student information.
- **Search Students:** Search for students and find their information.
- **Delete Students:** Remove student records that are no longer required.

## Technologies

- Java
- SQL Server
- JDBC
- Eclipse IDE
- Git & GitHub

## Getting Started

Clone the repository:

    git clone https://github.com/wadha442/Student_Managment.git
