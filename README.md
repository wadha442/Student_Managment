# Student Management System

## Description

Student Management System is a Java application designed to manage student and course information in an organized and simple way.

The system allows users to add, view, update, search, and delete student and course records.

This project was developed using Java and SQL Server as a simple example of building a student and course management application.

## Features

### Student Management

- **Add Students:** Add new students to the system.
- **View Students:** Display student records and their information.
- **Update Students:** Modify existing student information.
- **Search Students:** Search for students and find their information.
- **Delete Students:** Remove student records that are no longer required.
- **National ID:** Validate and use the National ID to manage student records.

### Course Management

- **Add Courses:** Add new courses to the system.
- **View Courses:** Display course records and their information.
- **Find Courses:** Search for courses using the course code.
- **Update Courses:** Modify existing course information.
- **Delete Courses:** Remove course records that are no longer required.
- **Course Code:** Validate course codes using the required format.
